# Заметки: Работа с Git в VS Code vs CLI

## Удобные функции Git в VS Code:
1. **Удобный просмотр diff (изменений):** Наглядное сравнение до/после с подсветкой синтаксиса перед коммитом.
2. **Интеграция GitLens (`git blame`):** Возможность мгновенно видеть автора и историю изменений прямо над строкой кода.
3. **Разрешение конфликтов (Merge Conflict Editor):** Удобные кнопки `Accept Current / Incoming Change` при возникновении конфликтов слияния.

## Что удобнее делать в терминале (CLI):
1. **Сложные операции и управление ветками:** Команды вроде `git rebase -i`, `git cherry-pick` и гибкая работа с `git log --graph` в CLI дают полный контроль и исключают случайные действия UI.
