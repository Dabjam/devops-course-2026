# Мои цели на семестр

## Цель 1 — Освоить основы DevOps и инструменты CI/CD
Изучить ключевые практики DevOps: настройку пайплайнов CI/CD, работу с Docker и автоматизацию деплоя. К концу семестра уметь самостоятельно настроить полный цикл от коммита до деплоя приложения.

## Цель 2 — Уверенно работать с Git и GitHub
Закрепить навыки работы с ветками, pull request'ами и code review. Научиться грамотно вести историю коммитов и работать в команде через GitHub, применяя Git Flow.

## Цель 3 — Выполнить все практические работы на оценку "отлично"
Сдать все лабораторные и практические работы в срок, разбираясь в каждом задании, а не просто копируя решения. Использовать каждую работу как возможность глубже понять материал.
