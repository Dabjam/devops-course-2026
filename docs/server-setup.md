## Развёртывание стека Docker (Практическая работа №7)

1. Установлен Docker Engine и Docker Compose; пользователь `devops` включён в группу `docker`.
2. Собран кастомный образ приложения `devops-app:1.0` на базе `python:3.12-slim` с запуском под непривилегированным пользователем `app`.
3. Описан стек `docker-compose.yml`:
   - `db`: контейнер `postgres:16-alpine`, изолирован в сети `backend`, данные сохраняются в томе `db_data`, настроена проверка `pg_isready`.
   - `app`: контейнер приложения Flask+Gunicorn, зависит от статуса `healthy` у СУБД, проброшен на `127.0.0.1:5000`.
4. Настроен обратный прокси Nginx:
   - В `/etc/nginx/sites-available/default` добавлен `location /app/` для маршрутизации внешних запросов к контейнеру приложения.
